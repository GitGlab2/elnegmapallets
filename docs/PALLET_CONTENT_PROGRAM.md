# برنامج توسيع محتوى البالتات والعبوات الخشبية

## الهدف

بناء مكتبة مرجعية موثوقة عن البالتات والعبوات الخشبية التي تصنعها شركة النجمة، تساعد العميل على اختيار المنتج المناسب وتمنح محركات البحث والأنظمة التي تجيب عن الأسئلة معلومات منظمة، دقيقة، وقابلة للاستشهاد. هذا البرنامج لا يعتمد على نشر مقالات كثيرة بسرعة؛ كل صفحة تنشر بعد مراجعة المواصفات والصور الفعلية من المصنع.

## قواعد النشر

1. لا تُنشر حمولة، معالجة، شهادة، أو مقاس ما لم يراجعه مسؤول فني في المصنع.
2. تكون الصورة الرئيسية للمنتج الحقيقي من المصنع كلما أمكن. الرسم التوضيحي يستخدم لشرح الأبعاد فقط ولا يحل محل الصورة الفعلية.
3. كل صفحة تجيب عن سؤال شراء أو استخدام حقيقي، ولا تعيد صياغة نفس المقال بكلمات مفتاحية مختلفة.
4. يكتب اسم المؤلف أو المراجع الفني وتاريخ المراجعة لكل دليل.
5. تُراجع الصفحات عند تغيير المواصفة أو خط الإنتاج، لا لمجرد تغيير تاريخ النشر.

## بطاقة البيانات المطلوبة لكل منتج

لا يبدأ تحرير صفحة منتج قبل اكتمال هذه البطاقة:

- الاسم التجاري داخل المصنع، والاسم الذي يستخدمه العميل، والاسم الإنجليزي.
- الاستخدامات المسموحة وغير المناسبة.
- الطول × العرض × الارتفاع، سماكات الألواح، عدد الدُكَم/العوارض، ونوع الدخول بالرافعة.
- حمولة ثابتة، متحركة، وعلى الأرفف، مع شروط الاختبار أو الاستخدام التي تجعل الرقم صحيحًا.
- نوع الخشب، التجفيف أو المعالجة الحرارية، والختم/الشهادات المتاحة فعلًا.
- المقاسات المتاحة كقياسي، وما الذي يمكن تفصيله حسب الطلب.
- ثلاث صور فعلية على الأقل: صورة المنتج بالكامل، لقطة القياس، ولقطة للتجميع أو المكوّنات. يفضّل إضافة رسم أبعاد واضح.
- اسم المراجع الفني وتاريخ آخر مراجعة ورقم المنتج الداخلي إن وُجد.

## مراحل التنفيذ

### المرحلة 0 — الأساس والتحضير (بدأت الآن)

- توحيد قائمة المقالات والمقاسات في واجهة واحدة.
- تحويل أدلة المقاسات الحالية إلى مقالات موحّدة قابلة للبحث والفهرسة.
- اعتماد تصنيف ثابت `sizes` للمقاسات، ثم إضافة تصنيف مستقل لبناء البالتات والعبوات الخشبية عند توفر أول مجموعة معتمدة.
- إضافة بيانات منظمة `Article` لكل مقال وتحسين العنوان والوصف والصورة الرئيسية.
- إنشاء هذا الملف كبطاقة عمل ومصدر للحالة قبل كل دفعة نشر.

**ناتج المرحلة:** مكتبة مقاسات موحّدة + أساس تقني لا يغيّر محتوى المنتج دون مراجعة.

### المرحلة 1 — الدفعة الأولى: هيكل البالتات

ينشر مقال مستقل لكل من:

1. بالتة الدُكَم: تركيبها، متى تناسب الرافعات والتحميل، مقارنات عملية مع المراين، والمقاسات التي ينفذها المصنع.
2. بالتة المراين/العوارض: شكل العارضة، اتجاه الدخول بالرافعة، الاستخدامات، والحدود التشغيلية.
3. بالتة السطح المغلق أو «السد»: تعريف الاسم المعتمد في المصنع، فائدته للعبوات الصغيرة أو الأسطح الحساسة، وحدود التنظيف والتهوية.

لكل صفحة: صورة رئيسية فعلية + صورة قياس + جدول مواصفات + حالات استخدام + أسئلة شائعة واقعية + روابط إلى المقاسات المناسبة وطلب عرض سعر.

### المرحلة 2 — الدفعة الثانية: العبوات الخاصة

1. بالتة العلبة: متى تستخدم، الارتفاعات أو الجوانب المتاحة، وسيناريوهات التخزين والشحن.
2. الصندوق الخشبي للشحن: الفرق بين الصندوق والبالتة، حماية المعدات، التهوية، التبطين، واشتراطات التصدير عند تطبيقها.
3. صفحة مقارنة عملية: أيهما أحتاج — بالتة دُكَم، مراين، سطح مغلق، علبة، أم صندوق؟

### المرحلة 3 — الصور والمخططات

- تصوير منتجات فعلية بخلفية نظيفة وإضاءة موحدة، مع ملف رئيسي عالي الدقة لكل مقالة.
- إنشاء رسم أبعاد من واقع القياسات المعتمدة فقط.
- تسمية الملفات بأسماء وصفية، وإضافة نص بديل يصف المنتج فعلًا، وربط كل صورة بالصفحة المناسبة.
- لا تستخدم صور مولّدة بالذكاء الاصطناعي كدليل على مواصفة أو منتج متاح؛ يمكن استخدامها كشرح بصري ثانوي فقط وبشكل واضح.

### المرحلة 4 — تحسين الظهور والقياس

- إضافة `Article` schema لكل دليل، و`Product` schema فقط للمنتجات التي تتوافر لها مواصفات وعرض بيع حقيقيان.
- ربط المقالات بصفحات التصنيفات والمنتجات والاتصال، مع Breadcrumbs واضحة.
- مراجعة العناوين والأوصاف والصور وبيانات الفهرسة عبر Google Search Console وRich Results Test بعد النشر.
- متابعة الاستعلامات التي تجلب ظهورًا، والأسئلة التي يكررها العملاء، ثم إضافة إجابات موثقة بدل مقالات مكررة.

## تعريف اكتمال المقال قبل النشر

- مراجعة فنية للمواصفات والمصطلحات.
- صورة فعلية وبديل نصي وصورة رئيسية مرتبطة بالمقال.
- عنوان واضح، وصف فريد، مؤلف/مراجع، وتاريخ مراجعة.
- جدول مواصفات صالح للمنتج نفسه، لا جدول عام منسوخ.
- روابط لمقالات ومقاسات مرتبطة، وزر تواصل يطلب المواصفات اللازمة للتسعير.
- اختبار الأداء على الهاتف وفحص البيانات المنظمة بعد النشر.

## مؤشرات النجاح

- فهرسة كل صفحة جديدة بنجاح، ثم نمو الظهور والنقرات لاستعلامات المنتج الفعلية.
- زيادة طلبات الأسعار التي تحمل المقاس أو نوع البالتة بدل الرسائل العامة.
- ظهور صفحات الأدلة في بحث الصور بفضل الصور الفعلية والنصوص البديلة الوصفية.
- استخدام فريق المبيعات للمقالات نفسها لإجابة العملاء وتحديد المنتج المناسب بسرعة.
